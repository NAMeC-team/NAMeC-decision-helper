# Ontologie
Ce fichier permet d'expliquer la partie ontologie, ou IA symbolique, du decision helper.

## Objectif
Construit le réseau de neurones logique qui sert de base au système décisionnel.

## Stack
- Protégé

## Composition
- **namec.ttl :** L'ontologie en format turtle. Chaque entité est créée dans le logiciel *Protégé*. Ensuite, des règles logiques sont créées, pour relier les entités entre elles, et ainsi construire une partie du monde centrée sur les robots et leur fonctionnement.
